# 问题 2 · 去掉「全年一次性求解」的说明

> 本文件夹回答一个问题：问题 2 定稿代码（`CUMCM-C/代码/problem2.py` 的 `solve_deliver`）把
> 365 天一次性建成一个联合 LP，它是否"一次看到全年数据"、有没有数据泄露风险？以及把这
> 个全局视野去掉后，结果差多少。

---

## 一、先厘清：数据泄露 vs 结构性前视

这是三个不同层次的问题，必须分开说。

### 1. 计划输入是否读到未来数据？—— 没有

`solve_deliver` 产出计划购电功率 ĝ 的 LP，**直接引用的变量只有电价、情景集 `q` 和同伴日的
负荷/光伏**，全年实测负荷 `L`、光伏 `P` 数组根本不进这个 LP。情景集的来源全部在当天之前：

| 数据入口 | 用的是什么 | 是否向后看 |
|---|---|---|
| 低需求日分组 {周五,周六} | 暖机期（前 31 天，1 月）的日均净负荷 | ✅ 报告窗之前 |
| 第 d 天情景集 `peers` | `range(max(0,d−6), d)` 内同组**历史**日 | ✅ 严格向后 |
| γ=1 可交付下界 `q = min_ω(P−L)` | 同组**历史**日的负荷/光伏 | ✅ 向后 |
| 应急期望 `E[e]` | 同组**历史**日的负荷/光伏 | ✅ 向后 |
| 执行层 `execute_soc_causal` | 逐槽只用当前 `L[t], P[t], SOC` | ✅ 逐槽因果 |

**结论：计划 ĝ 无数据泄露。** 每天只看过去 6 天同组日 + 当天 0:00 已知的信息。

### 2. 全年一次性求解是不是前视？—— 是，但是"结构性前视"，不是"读未来数据"

`solve_deliver` 是**全年一次性联合 LP**：`linprog` 一次解 52,560 个 ĝ，并用 SOC 递推 +
**终端约束 `S_0 = S_T = 6000`**（全年能量中性，自加假设）把 365 天耦合在一起。LP 知道自己
年末必须回到 6000，于是能统筹全年 SOC 轨迹（例如"12 月缺口大，11 月多留电"）。

它读的**仍是历史数据 + 终端锚**，不读未来负荷/光伏——所以这不是数据泄露，而是"带终端锚的
全年规划"，是 clairvoyant 的规划层，不是在线策略。归档 `问题2_求解归档.md` 已主动声明这一点。

### 3. 什么才是"真用全年数据"？—— 只有哨兵，且它本来就该用

`solve_full_year(L−P)` 这个**完美预见下界**确实用了全年实际 `L/P`。但它是下界基准（任何
策略都做不到、低于它即 bug），不是交付物。交付物来自 `solve_deliver(1.0)` + 因果执行。

## 二、本脚本做了什么：把全年联合 LP 改成单日 LP

`p2_daily_lp.py` 把 `solve_deliver` 的**全年一次性联合 LP** 改成严格在线：

- 第 d 天 0:00，只用【过去 6 天同组历史日】作情景集 + 当日已知起始 SOC；
- 解一个 **144 槽的单日 LP**，终值 `SOC_144 = SOC_0 = 6000`（单日能量中性，问题 1 条件②口径）；
- 再用 `execute_soc_causal` 因果执行当天，SOC 传给次日。

**与 problem2.py 唯一区别** = "单日 LP vs 全年联合 LP"。其余全部逐字一致：

| 项 | 取值 |
|---|---|
| 低需求日分组 | 暖机期日均净负荷最低两天 = {周五,周六}，回看 span=6 |
| γ=1 可交付 | `q_t = min_ω(P_ω − L_ω)`（裸 P−L），约束 `CM − G − D ≤ q` |
| 目标 | `Σ p_t·ĝ_t + Σ (5p_t/K)·E_ω,t`（应急期望 5 倍价） |
| 执行 | 逐槽贪婪 先放覆盖缺口→富余再充→仍缺才紧急，SOC∈[1200,10800] |
| 结算（口径 B） | `Σ p·ĝ + Σ 5p·e`，统计窗口 2/1–12/31（前 31 天暖机） |
| 购电功率上界 | 无上界（与 problem2 定稿一致，`G ∈ (0, +∞)`） |

单日 LP 的变量布局与 `solve_deliver` 完全相同（`G, D, S, CM, E`），只是把 `T=52560` 缩成
`N=144`、把"年末一次锚"换成"每天一锚"。

---

## 三、为什么差值这么小（机理）

问题 2 **每天电价相同**（`price_day` 重复 365 天），跨日无套利空间。全年联合 LP 唯一能
多做的就是"年末 SOC=6000 锚"允许的跨日能量微调，其余套利全部发生在**当天电价曲线内**，
单日 LP 同样能做到。所以去掉全局视野只差 0.1% 量级。
