## 2. ★ 关键结构发现：τ 与情景集是**两个可互相替代的缓冲旋钮**

> 这是 O2 的立论基础，也是本次优化唯一的"新机理"。归档 §7.5 把它作为**假说**记录
> （"两个不确定性响应机制是叠加的，尚未做决定性验证"）。本节把它推成**可证的结构事实**，
> 并给出决定性实验。

### 2.1 代码事实：`REC=1` 时，τ **唯一**的进入通道是情景集的中心

追索路径下，计划层的调用链是（`problem4_3.py`）：

```
h  = wquantile(残差池, PR, TAU_B[e])          # ← τ 在此进入
Nt = F_hat[d,0,:] + h                          # 分位缓冲
gh = plan_day_recourse(soc, _scenarios(d, Nt), pr_plan, SOC0)[ĝ]
                     └─ _scenarios(d, Nt) = Nt + (actual_net[同伴] − 同伴均值)
```

`_scenarios` 把 `Nt` **只当作一个加性平移量**用掉（`Nt[None,:] + 形变`）。
于是：

```
ĝ  ≈  F̂  +  h(τ)  +  Q(情景形变)
              ↑            ↑
         τ 分位缓冲    追索 LP 自己的分位抬升
```

**h(τ) 与 Q(·) 是对同一份不确定性的两次抬升。** τ 并不是一个"独立的可靠性垫层"，
它只是**情景集中心的位移**；LP 随后又按自己的临界比在这批情景上抬了一次。

### 2.2 实测印证：单维最优 τ 落在**中位数**，不是静态临界比

τ 的静态临界比由两侧代价推得：0:00–6:00 块不可调整、缺口只能按 5p 紧急补救 ⇒
`c_u/(c_u+c_o) = 4p/(4p+p) = 0.80`；后三块可用 1.5p 兜底 ⇒ 临界比低得多。
但 `diag_p4_tau.py` 实测（归档 §5.2、`_p4_tau.txt`）：

| 维度 | 静态理论值 | **实测最优** |
|---|---:|---:|
| τ₀（0:00 块） | 0.80 | **0.50** |
| τ'（第 1–3 块） | ~1/3 | **0.48** |
| τ''（调整层） | — | **0.34** |

**τ 取中位数 ⟺ h ≈ 0 ⟺ 缓冲几乎全部由情景对冲提供。**
"两个机制叠加、有效临界分位低于静态值"——这正是它的签名。
`_p4_tau.txt` 当初把它记为"静态理论被实测推翻"，**真正的原因是这个**：
理论值算的是"唯一缓冲"的分位，而模型里缓冲有两份。

### 2.3 决定性实验（本次执行）

1. **阻尼扫描**：把情景中心从 `Nt` 改为 `F̂ + λ·h`（λ=1 即交付、λ=0 即 τ 完全失效、
   缓冲全部由情景对冲承担），联合重扫 τ。
2. **反向验证**（归档 §7.5 自己提出的判据）：**真实预报 + 单情景**下重扫 τ，
   看最优是否向静态值 0.80 回移。若回移 ⇒ 双重对冲确认；若不回移 ⇒ §2 的机理不成立，
   须撤回。

## 3. 五条优化路线

### O1｜τ 分位重扫（五维坐标下降）

- **机理**：τ 是**替代旋钮**（§2），其最优位置随另一旋钮的强度移动 ⇒ **只能扫，不能推**。
  本文件 docstring 早已写明"τ 的最优位置不随配置移动"的旧断言已作废。
- **上界证据**：三维联合调平已实测 **−49,620.85 元（−0.344%）**（`_p4_tau.txt` 第四节，
  联合最优 (0.50, 0.48, 0.34)）。当时**只试了手挑的 6 个点**，不是搜索。
- **本次做法**：五维（τ₀/τ₁/τ₂/τ₃/τ''）坐标下降。**五维而非三维**的理由：交付记法把
  第 1–3 块绑成同一个数，但附件 3 逐档预报质量本就不同（净需求 RMSE 矩阵显示 6:00/12:00
  档有独立信息、18:00 档无增量）⇒ 三块的不确定性结构不同，没有理由用同一个分位。
- **工具**：`代码/诊断/diag_p4_tau_opt.py`（已备，此前从未运行过）。
- **成本/风险**：换 τ ⇒ 与问题 3 的 τ 不再相同 ⇒ §6.1「波动电价不改策略、只改账单」
  （逐槽相异 0/48,096）的**受控对照断掉**，须降级为**明确标注的受控消融**。

### O2｜双重对冲解耦（核心）

- **机理**：§2。
- **参数化**：情景中心 `F̂ + λ·h`，λ ∈ [0,1] 逐块可调。λ 与 τ 是**两个方向**：
  τ 只能沿"残差分位数"这一条曲线改变 h，而 λ 是**线性缩放**。二者只有在残差分布形状
  完全正确时才重合 ⇒ λ 带来真正的额外自由度。
  - 变体：把 h 从"分位数"直接改成"**扫描的平移量**"（绕过 τ 的非线性参数化）。
- **上界**：交付 − 联合最优 ≥ 146,782（O1 的实测值即此机制的一次体现）；λ 放开后可能更多。
  ⚠ 旧版这里写的是 49,621（手挑 6 点的估计），**已作废**。
- ⚠ **纪律**：X_single 省的 581,820 **不是**收益（推论 2）。
- **交付后的定位**：若 O2 有效，论文里"模型改进"一节的标题应是
  **"识别并消除重复的风险缓冲"**，而不是"调参"。

### O3｜净需求预报器改进

- **现状**：`L_base[d]` = 低需求日分组内、回看 `GRP_SPAN=7` 天的**同伴日均值**。
  低需求日只占 2/7 个星期几 ⇒ 回看 7 天里平均只剩 **约 2 个样本**，
  逐槽均值噪声极大。这是"粗糙"二字的来源。
- **上界**：711,378（预报误差总代价），可回收的只是一部分。
- **候选方向**（按预期收益/风险排序）：
  1. **水平校正前移**：调整层已用"当日已发生时段的实测/基准比值 r"修正后续时段
     （`LEVEL=1`，实测是 v3 相对归档最大的缺口），但 **0:00 块拿不到**（它不可调整）。
     ⇒ 把 r 从"日内修正"前移成"点预报的一部分"（例如用近 1–2 日的水平残差）。
  2. **池化口径**：同组日只用于估"日水平"，逐槽形状改用全体历史 ⇒ 样本量 2 → 30+。
  3. **回看窗口**：`GRP_SPAN` 扫描（P2/P3 都固定 7；P3 实测 span6 更贵）。
  4. **光伏侧混合**：附件 3 的 0:00 档已知**比历史统计还差**（问题 2 归档）
     ⇒ 与"同槽历史均值"做凸组合。
- ⚠ **风险**：任何改 `F̂` 的操作都会移动残差池 ⇒ 移动 h 与 τ 的最优位置
  ⇒ **必须与 O1/O2 联动重扫**，不能单独报增益。

### O4｜价格感知执行器

- **现状**：`exec_causal_day`（`problem4_3.py:885`）逐槽"先放电、再充电"，
  **完全不看价格**——此前是本模型最可疑的启发式。
- **上界**：133,623 元（(iii) 段），但那是**执行器 ＋ 0:00 承诺机制合在一起**量的，
  执行器单独只占其中一部分（归档 §7.5 已把这个细分缺口标记为"已知、未闭合"）。
- **机理**：在分时电价下放电时序**不是中性的** —— 在**高价缺电槽**放电（省 5p）优于在
  低价缺电槽放电。附件 1 是 **144 槽逐槽变化的剖面**（实测 137 个不同取值，最值
  0.3713 / 1.3952），不是平价，故这个自由度真实存在。
- **实施约束**：读法 B 下 0:00 只能拿到附件 1 的**公布剖面**，日内实际价 PR 未知
  ⇒ 执行层可用的价格信息本身受限，增益可能远小于 133,623。
- **顺带闭合 §7.5 的缺口**：本路线跑完即可把 (iii) 拆成"执行器"与"0:00 承诺结构"两段。

### O5｜日末 SOC 回位（自加假设）

- **上界**：47,895 元（3.0%），实测自 `_p4_oracle.txt` 哨兵 A→B。
- ⚠ **不建议改动交付**：它是与问题 2/3 逐字同构的模型约定，去掉会破坏四问的可比性；
  而归档 §7.5 结论 2 已判定"相对它的解释负担，这是一条**便宜**的假设，可以放心保留"。
- **只作消融报告**，不进入交付。

### 明确不做

- **多阶段随机规划**（把调整层做成完整的多阶段树）：题面只给 4 档日预报，
  阶段结构没有对应信息源，收益无法兑现。
- **改哨兵**：哨兵是下界，不是策略；任何"让哨兵更贵"的操作都不构成优化。
- **任何以牺牲可比性为代价、换 < 0.5% 收益的结构改动**——除非它同时带来机理上的清晰
  （O2 属于后者）。
