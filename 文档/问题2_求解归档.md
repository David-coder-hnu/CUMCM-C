# 问题 2 求解与归档文档

> 题目：2026 年高教社杯全国大学生数学建模竞赛 C 题「微网与外部电网电力调控策略」——问题 2
> 求解日期：2026-09-11
> 求解环境：Python 3 + SciPy（`scipy.optimize.linprog`，HiGHS 求解器，稀疏矩阵）

---

## 1. 问题概述

若每天的电价相同、而小区负载与光伏发电功率随时间（逐日）变化，要求：

1. 微网提供的电能**不可低于**小区负载，若低于则需向外网**紧急购电**（电价为交易时刻的 5 倍）；
2. 除紧急购电外，其余时段购电费均按**计划购电量**计算；
3. 在每天 **0:00 制定当天**的计划购电策略，目标**尽可能节省购电费**。

**建模解读（方案 B，已与团队确认）**：

- **预测式计划 + 紧急购电**：0:00 制定计划时手里没有"当天实际负荷/光伏"，只有一份**预测**。计划按预测制定，实际（附件 2）偏离预测的缺口 → 5 倍价紧急购电。
- **储能跨日连续**：初始 6000 kWh（2025-1-1 0:00）、年末回 6000 kWh（全年能量中性），SOC 自由漂移。问题 2 原文**没有**"0:00 与 24:00 储电量相同"约束（那是问题 1 的）。

问题 2 的本质是：**在没有天气预报的情况下，"计划 vs 实际"的偏差必然产生紧急购电**，预测越准、紧急购电越少。

## 2. 数据与参数

### 2.1 关键数据发现：附件 1 即"全年平均日"

交叉验证发现（`max|附件1 − 全年平均|` 仅 5×10⁻⁵，光伏因 4 位小数舍入差 0.04）：

| 附件 1 的列 | 等于 |
| --- | --- |
| 电价 | 附件 4 全年平均电价 |
| 小区负载 | 附件 2 全年平均负载 |
| 光伏预测功率 | 附件 2 全年平均光伏 |

即附件 1 是"全年平均的典型日"。问题 1 用这个典型日做确定性求解；问题 2 的"每天电价相同"即取附件 1 的电价。

| result2 模板 | 计划购电量(335×147) + 充放电量 + 紧急购电量 | 覆盖 2/1–12/31（1 月为暖机期） |

### 2.3 附录 1（储能参数）

| 参数 | 数值 |
| --- | --- |
| 最大容量 | 12000 kWh |

### 2.4 建模关键设定（已与团队确认）

- **效率方向**：充电、放电各打 9 折（`SOC += 0.9·c·Δt`，放电时电池吐出 `d·Δt/0.9`），往返 81%。
- **不允许向电网售电**：多余光伏弃光处理（记入弃光量 `s_t`）。
- **全年能量中性**：初始 `SOC(1-1 0:00)=6000`、年末 `SOC(12-31 24:00)=6000`，避免年末"清空电池"的边界伪影（该约束仅影响 12 月下旬）。

## 3. 预测方式的选择

"计划购电量"由 0:00 的预测决定，因此**预测方式直接决定紧急购电的多少**。我们对 16 种预测方式做了横向对比（统一框架：预测做计划 → 实际偏差算紧急购电，储能跨日连续），统计窗口 2/1–12/31：

| 预测方式 | 紧急购电量(kWh) | 总购电费(元) |
| --- | ---: | ---: |
| 完美预见（下界基准） | 0 | 12,229,461 |
| **负荷=同星期几(4周) + 光伏=近7天** ⭐ | **1,058,885** | **16,319,245** |
| 负荷=同星期几(4周) + 光伏=前一天 | 1,148,315 | 16,710,952 |
| 同星期几(1周) | 1,207,868 | 16,926,914 |
| 同星期几(2周) | 1,208,047 | 16,934,523 |
| 同星期几(4周) | 1,378,611 | 17,626,017 |
| 同星期几(8周) | 1,830,642 | 19,514,296 |
| 前一天（持续法） | 2,596,448 | 22,822,642 |
| 近7天平均 | 3,109,935 | 24,532,709 |
| 指数加权 α=0.5 | 3,170,235 | 24,936,546 |
| 近14天平均 | 3,135,259 | 24,614,085 |
| 近30天平均 | 3,218,324 | 24,910,192 |
| 全年平均（附件1） | 3,239,685 | 25,121,732 |
| 指数加权 α=0.1 | 3,273,888 | 25,171,473 |
| 指数加权 α=0.3 | 3,327,765 | 25,494,001 |
| 近3天平均 | 3,640,893 | 26,922,527 |

**结论**：最优预测是**分开预测**——负荷用"同星期几（近4周平均）"、光伏用"近7天平均"。

- **负荷为何用"同星期几"**：小区用电有很强的**周周期**（工作日 vs 周末差别大）。拿"前一天"预测周一，会系统性低估（周日是周末、负荷低）；拿"过去几个周一"的平均，正好代表"周一通常什么样"。
- **光伏为何用"近7天"**：光伏由**季节**（变化慢）+**天气**（逐日乱跳）决定。"近7天平均"既够近、能反映当前季节（不会像全年平均那样夏冬失真），又抹掉了某一天的天气噪声。
- **为何分开预测**：负荷和光伏的驱动因素不同（人的作息 vs 天气），单一方法套两者是"迁就"，分开各用最优才最准。

> 与"完美预见下界"（1222.9 万元）之间约 409 万元的差距，就是"没有天气预报"这一先天信息不足的代价，正好为问题 3（引入预报 + 调整）留下改善空间。

## 4. 数学模型

时间离散为全年 365 天 × 144 个 10 分钟区间，共 `T = 52560` 个区间，`Δt = 1/6` 小时。设 `L̂_t`、`P̂_t` 为预测负荷/光伏（见 §3），`L_t`、`P_t` 为实际负荷/光伏（附件 2）。

### 4.1 计划阶段（全年连续 LP，用预测值）

决策变量（每区间 t）：购电功率 `ĝ_t ≥ 0`、充电 `ĉ_t ∈ [0,5000]`、放电 `d̂_t ∈ [0,5000]`、弃光 `ŝ_t ≥ 0`、储电量 `SOC_t ∈ [1200,10800]`。

$$
\min \; \sum_t \text{price}_t \cdot ĝ_t \cdot \Delta t
$$

约束：

**① 功率平衡**：$ĝ_t + P̂_t + d̂_t = L̂_t + ĉ_t + ŝ_t$

**② 储电递推**：$SOC_{t+1} = SOC_t + 0.9\,ĉ_t\,\Delta t - \dfrac{d̂_t\,\Delta t}{0.9}$

**③ SOC 上下限**：$1200 \le SOC_t \le 10800$

**④ 首尾边界**：$SOC_0 = SOC_T = 6000$

### 4.2 紧急购电（实际 vs 计划）

计划执行时，实际负荷/光伏与预测不一致，供电缺口由 5 倍价紧急购电补足：

$$
e_t = \max\left(0,\; L_t + ĉ_t - ĝ_t - P_t - d̂_t\right)
$$

### 4.3 总购电费

$$
\text{总费用} = \underbrace{\sum_t \text{price}_t\,ĝ_t\,\Delta t}_{\text{计划购电费}} + \underbrace{\sum_t 5\,\text{price}_t\,e_t\,\Delta t}_{\text{紧急购电费}}
$$

## 8. 物理洞察与结论

1. **紧急购电是"没有预报"的必然代价**：计划按预测制定，实际负荷/光伏一偏离，缺口只能靠 5 倍价补足。全年紧急购电量 105.9 万 kWh、紧急购电费 411.7 万元，约占计划购电费的 34%——预测误差的惩罚很重。

2. **负荷的周周期是最大的预测信息**：把负荷预测从"前一天"换成"同星期几"，紧急购电量从 259.6 万降到 105.9 万 kWh（-59%），说明负荷的工作日/周末规律是最值钱的一条信息。

3. **储能跨日连续、自由漂移**：0:00 储电量在 [1665, 8550] kWh 间浮动（不再锁死 6000），冬季夜充偏高、夏季靠白昼光伏填满偏低。

4. **季节差异**：冬至（12.21）紧急购电最多（4261 kWh，预测误差最大），夏至（6.21）较少（2181 kWh）；计划购电费夏低冬高，与光伏/负荷的季节性一致。

5. **与问题 3 的衔接**：问题 3 引入附件 3 的天气预报后，"计划"将更准，紧急购电会明显下降，并新增"调整购电"机制——这是本文埋下的改善方向。
